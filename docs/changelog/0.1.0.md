# dsh-reduce-effects v0.1.0

Date: 2026-09-24

首个发布版本. 给 DSH Web 前端加一个 "前端特效" 设置页, 按分类关掉动画, 毛玻璃, 阴影, 渐变与 JS 动效, 降低浏览器渲染负担. 所有开关默认打开, 此时界面与原生 DSH 一致.

## Highlights

- Settings 新增 "前端特效" 页: 一个总闸加八个分类开关, 改动即时生效, 并写入当前 profile 的 settings 文档.
- 关掉分类只停对应特效: 过渡压到 1 毫秒, 装饰动画按关键帧名逐个收起, 加载指示器可以单独保留.
- 总闸只决定各分类生不生效, 不改写它们自己的值: 关掉时各分类变灰并保留原值, 重新打开即原样恢复.

## Features

- 动画与过渡: 装饰性动画停掉, 过渡压到 1 毫秒并保留 `transitionend`.
- 加载与进度动画: 按关键帧名 (spin, progress, busy, pending, blink, dot 等) 识别加载反馈, 单独控制.
- 毛玻璃与背景模糊: 去掉菜单与浮层的 `backdrop-filter`.
- 平滑滚动: 关掉滚动与跳转的缓动.
- 标题 hover 滚动: 侧栏会话标题不再作为滚动容器, 停在省略号处.
- 阴影与超椭圆圆角: 去掉面板与文字阴影, 含由阴影绘制的那条 0.5px 描边.
- 渐变背景: 去掉渐变底纹, 渐变文字交还 `currentColor`.
- JS 动效: 覆盖 `window.matchMedia`, 让 `prefers-reduced-motion` 查询走即时分支, 卸载时恢复原函数.

## Known Limitations

- 与系统的 "减少动态效果" 是叠加关系, 插件不修改系统设置.
- 只覆盖 Web 客户端; 桌面端窗口材质 (macOS vibrancy, Windows acrylic) 由系统与 Electron 负责.
- 关掉 "JS 动效" 会影响所有读取 `prefers-reduced-motion` 的代码, 包括其他插件; 已经渲染出来的界面可能需要刷新一次.
- DSH 前端的样式会随版本变化, 新出现的特效类别需要在本插件里补充规则.

## Upgrade Notes

1. 执行 `dsh plugin --profile web add azazo1/dsh-reduce-effects` 安装, 固定版本使用 `#v0.1.0`.
2. 预构建包见 GitHub Release 的 `dsh-reduce-effects.tgz`, 安装时跳过 `allowBuilds`.
3. 安装后重启 `dsh web`, 浏览器里刷新一次页面.
4. 验证方式: 打开 设置 > 前端特效, 关掉 "动画与过渡", 入场动画应立即落到终态; 关掉 "加载与进度动画", 进度条与加载指示器应停止转动.
