# dsh-reduce-effects v0.2.0

Date: 2026-09-25

设置入口从设置侧栏的独立页面搬到插件页的配置卡片, 改用官方表单控件, 并新增 "文字流光" 一档开关; 引擎版本线抬到 `0.1.7-rc.2`. 还在旧路径上找设置的用户请先看 Upgrade Notes.

## Highlights

- 开关搬到 插件 > dsh-reduce-effects 卡片: 九个开关走官方 `SettingsForm` 与 `Switch`, 改动先留在卡片里, 点 "保存" 才写进 profile 的 patch 层并立即生效.
- 新增 "文字流光" 开关: 单独收掉运行中节点文字上来回扫动的高光, 以及思考行与技能行整行扫过的那道光.
- 适配 `0.1.7-rc.2` 引擎线: 毛玻璃补上新的菜单填充 token, 标题 hover 滚动规则跟着状态点槽调整, 依赖范围放宽到 `>=0.1.7-rc.2 <0.2.0`.
- 每个字段带 "已覆盖" 标记与重置入口, 重置后该字段回落到组合层默认值.

## Breaking Changes

- 设置位置: 设置侧栏不再有 "前端特效" 页, 开关只出现在 插件 > dsh-reduce-effects 卡片上. 迁移方式: 直接打开插件页, 已经保存过的配置值原样保留, 不需要重新填.
- 生效时机: 改动不再即时落盘, 要拨完开关再点卡片上的 "保存", "放弃" 用来丢掉草稿. 迁移方式: 调整后点一次保存, 卡片上会显示未保存状态.
- 引擎版本线: 要求 `@deepseek-ai/dsh-*` 落在 `>=0.1.7-rc.2 <0.2.0`, 精确锁在 `0.1.7-rc.1` 的部署会被兼容性 preflight 判为不满足并整行禁用. 迁移方式: 先把 DSH 升到 `0.1.7-rc.2` 或更新的 `0.1.x` 再装这个版本.

## Features

- 文字流光: 关掉后按元素上的 `data-text-shimmer` 收掉 `TextShimmer` 的渐变颜料与扫动关键帧, 并去掉思考行与技能行 `::after` 上那道 300px 宽的整行扫光. 这一档是单向的: 关 "渐变背景" 或 "动画与过渡" 时仍会顺带把这两道光收掉, 它只是更窄的一条收法.
- 插件页卡片: 配置界面改用官方表单控件, 总闸关闭时分类开关变灰不可点, 但各自的值保留, 重新打开总闸即原样恢复.
- 桌面端: 文档补上 `desktop` profile 的安装路径, 它由 Electron 应用独占管理, `dsh plugin` 会拒绝该 profile, 只能在应用内的插件管理器里装.

## Bug Fixes

- 界面文案: 迁移时被改短的标签恢复成原文案 (阴影与超椭圆圆角 / 渐变背景 / JS 动效), 与 README 表格重新对齐.
- 毛玻璃: `0.1.7-rc.2` 起菜单材质改由新的 `MenuSurface` 用自己的 `--dsw-menu-surface-fill` 画, 只覆盖别名 `--dsw-specific-menu` 会在这类菜单上留下半透明底, 现在一并覆盖.
- 标题 hover 滚动: `0.1.7-rc.2` 的状态点槽改成无条件渲染, 标题不再落到第 1 格, 旧规则会打到状态点槽上, 现在只认行内第 2 个格子.
- 文字流光: 关掉流光后思考行与技能行上的整行扫光仍然在, 它是行容器伪元素上的另一道渐变而不是 `TextShimmer`, 只认 `data-text-shimmer` 的那一档碰不到; 现在按渲染期标记定位行容器并把伪元素的 `content` 去掉, 只停动画会留下起始帧 `left: 0` 的那块渐变.

## Upgrade Notes

1. 升级到 v0.2.0: `dsh plugin --profile web add azazo1/dsh-reduce-effects#v0.2.0`, 或安装 GitHub Release 上的预构建包 `dsh-reduce-effects.tgz`.
2. 桌面端在应用内的插件管理器里装, 填入对应的包名或 tarball 地址.
3. 安装后重启 `dsh web`, 浏览器里刷新一次页面.
4. 验证方式: 打开 插件 > dsh-reduce-effects, 关掉 "文字流光" 并保存, 运行中的节点文字应当不再扫光, 思考行与技能行上那道整行扫光也应当消失. 旧配置里没有 `textShimmer` 键, 升级后按开启处理, 界面与升级前一致.
