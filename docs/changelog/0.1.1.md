# dsh-reduce-effects v0.1.1

Date: 2026-09-24

修掉一个只在关掉 "渐变背景" (或直接关掉总闸) 之后才出现的显示问题: 会话页底部的输入区会变透明, 滚动中的消息从输入框区域透出来. 其余行为与 v0.1.0 一致.

## Highlights

- 关掉 "渐变背景" 或总闸后, 会话页底部的输入区重新有一层不透明的主题底色, 消息不再从输入框后面透出.
- 顺带去掉毛玻璃规则里写死的暗色兜底值, 亮暗主题都只走主题 token.

## Bug Fixes

- 渐变背景: DSH 把输入区那条底部区域的底板画在 `background-image` 上 (顶部 36px 由透明渐隐到页面底色), 关掉渐变时这条底板被一并移除, 该区域整块透明; 现在改为补一层 `--dsw-alias-bg-base` 纯色底, 并且只在输入区固定在底部 (active 相位) 时生效, 空会话居中时不额外加底色. 代价是顶部 36px 由渐隐变成硬边.
- 毛玻璃: `--dsw-specific-menu` 不再写字面量兜底值. 该层色 token 亮暗两套主题都有定义, 写死的值只可能是其中一套主题的近似色, 万一 token 缺失就会在另一套主题下用错色.

## Upgrade Notes

1. 升级到 v0.1.1: `dsh plugin --profile web add azazo1/dsh-reduce-effects#v0.1.1`, 或安装 GitHub Release 上的预构建包 `dsh-reduce-effects.tgz`.
2. 安装后重启 `dsh web`, 浏览器里刷新一次页面.
3. 验证方式: 打开 设置 > 前端特效, 关掉总闸 "全部特效", 滚动一个较长的会话, 底部输入区应当仍是不透明的主题底色, 消息不会从输入框后面透出来.
